## Constraints
- **No new dependencies** — Tailwind CSS v4 utilities only
- **Theme tokens** — Use `@theme` tokens already defined in `src/assets/main.css`: `bg-paper`, `text-ink`, `bg-neutral-50/100/...`, `bg-accent`, `text-success`, etc.
- **Preserve** the existing `Mainlayout.vue` sidebar behavior (already hides/shows correctly at `lg:`)

- **Preserve** all existing functionality (stores, API calls, routing)

## Decision Log

| Decision | Rationale | Rejected Alternatives |
|----------|-----------|----------------------|
| Use `@theme` tokens (`bg-paper`, `text-ink`, etc.) | Already configured; consistent with rest of app | Introduce new color tokens; use raw `bg-white` |
| Preserve `Mainlayout.vue` sidebar behavior | Already works well; user said "preserve current behavior" in scope question | Refactor sidebar; collapse to off-canvas everywhere |
| Preserve `auth/*` indigo design | Different design system, works well, intentional | Unify to modern theme (would be a full redesign) |
| Use Tailwind v4 default breakpoints (sm=640, md=768, lg=1024, xl=1280) | Project default; matches current usage | Custom breakpoints (would require config change) |
| Tables get `overflow-x-auto` on mobile | Data-heavy tables don't fit on small screens; horizontal scroll is standard pattern | Stack table rows into cards (complex, breaks semantics) |
| Dashboard pages unified to modern theme | User picked "Full pass with smart defaults" which includes style unification | Keep raw gray (would look inconsistent) |
| Chunk 6 is the heaviest (7 files, major refactor) | Dashboard pages are the biggest gap; needs dedicated focus | Spread dashboard changes across other chunks (harder to verify) |

## Risks

| Risk | Likelihood | Mitigation |
|------|------------|------------|
| Dashboard style unification introduces visual regressions | Medium | Verify each dashboard page individually in Chunk 6; compare before/after screenshots |
| TrackOrder timeline overflows at 320px (5 horizontal stages) | Medium | In Chunk 4, verify and fix by reducing icon size or wrapping |
| Build fails due to undefined class (e.g. `text-elegant-black` in SocialAuthButtons) | Low | Already identified in Chunk 2; will be fixed |
| Dashboard tables unscrollable on mobile (no `overflow-x-auto`) | Medium | Each table in Chunk 6 explicitly gets the wrapper |
| Auth modal/dialog padding at 320px | Low | Visual check in Chunk 7 |
| Auth pages look "out of place" vs rest of app | Low (accepted) | Explicit decision; not a bug |
